典型演示场景

三种最常见用法，均可在 dev 环境本地复现。

📖 文档阅读

飞书 / 浏览器文档前台打开，Companion 语音说「用中文阅读并总结」。Cursor 通过 MCP 截屏、微调滚屏、写中文摘要并口播。

companion_socket_connect_and_wait → 读屏循环 → companion_task_complete

☎️ 双工语音

按住 PTT 说话，边缘模型即时 ack + 简单动作；Cursor 接管复杂规划。TTS 与 Live2D / VRM 口型同步。

voice.stt.final → duplex → Cursor MCP → companion_speak

🖱 桌面自动化

MCP 提供 mouse_move、mouse_click、mouse_scroll、keyboard_*。禁止 cmd+tab；用点击文档区聚焦，小步滚屏阅读。

activate_document_app · get_screenshot · mouse_scroll

使用指导

  1. 安装依赖

    macOS：Rust、Node 20+、Python 3.12。为 Cursor 与 Python 授予屏幕录制与辅助功能。

    git clone https://github.com/jsCanvas/hui-agent.git
cd hui-agent/repo/client/mcp-server
python3.12 -m venv .venv && .venv/bin/pip install -e ".[dev]"
cd ../ui && npm install && cd .. && npm install

  2. 启动桌面端

    cd hui-agent/repo/client && npm run dev

    Companion 浮层出现在右下角；Daemon health：http://127.0.0.1:18766/health

  3. 配置 Cursor MCP

    将 mcp-server/.venv/bin/python -m hui_mcp 写入 Cursor MCP 配置，启用 hui-agent-desktop。

  4. 连接 Socket Relay

    在 Cursor 中说「连接 socket」，或运行：

    ./scripts/connect-cursor-socket.sh

    或调用 MCP companion_socket_connect_and_wait，Companion 显示「监听中」。

  5. 发起任务

    Companion 语音（PTT）或文字输入。任务完成后 companion_task_complete 默认 auto_wait 自动继续监听。
