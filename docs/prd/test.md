## 图片一：营销中心 · 创建 SPU

**页面路径**：营销中心 → 返回商品列表 → 创建 SPU

### 基础信息

| 字段 | 说明 |
|------|------|
| SPU 名称 | 英文、阿语两个输入框 |
| 商品 Tag | 点击「+」添加标签 |
| 类目信息 | 下拉选择「请选择类目信息」 |
| 售后类型 | 文本输入 |

### 图文信息

- **英文商品图（0/5）**：1 张主图 + 4 张辅图占位
- **阿语商品图（0/5）**：同上结构
- **商品图格式**：png / jpg / jpeg，最小 600×600px，单张 ≤ 5MB，可拖拽排序
- **英文主视频 / 阿语主视频**：mp4，≤ 100MB，比例 1:1 / 3:4 / 9:16（最小 600×600px），时长 ≤ 60s（建议 30s）
- **商品详情页**：左侧手机预览 + 右侧资源上传
- **英文详情页编辑（0/20） / 阿语详情页编辑（0/20）**：单图宽高比 ≤ 500×2000px，≤ 5~6MB，jpg/jpeg/png，可拖拽排序

### 物流信息（同页下半）

| 字段 | 类型 |
|------|------|
| 发货方式 | 下拉 |
| 物流商 | 文本 |
| 发货时效（用户可见） | 下拉 |
| 服务（用户可见） | 下拉 |
| 是否包邮（用户可见） | 下拉 |
| 运费（用户可见） | 文本 |
| 发件人 / 联系电话 / National address | 文本 |
| 发货 prov / city / area（用户可见） | 三级下拉 |
| 详细地址 | 多行文本 |

### 展示参数

- 表格列：**属性** | **展示参数** | **展示参数**
- 底部 **「+ 继续添加」** 增行

### 底部操作

**取消** | **保存草稿** | **保存并创建 SKU**
